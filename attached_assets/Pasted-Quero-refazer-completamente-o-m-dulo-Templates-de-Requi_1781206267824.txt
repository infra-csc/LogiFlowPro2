Quero refazer completamente o módulo “Templates de Requisição” do EventFlow.

Hoje a tela ficou simples demais e não atende ao objetivo principal. O objetivo desse módulo é permitir que o administrador cadastre modelos padrão de itens por área/departamento, para que, ao criar uma nova requisição de materiais para um evento, o usuário possa escolher um template e os itens já venham pré-preenchidos automaticamente, facilitando muito a inserção.

Exemplo real:
Área/Departamento: Percurso

Itens padrão do template:
- Cavaletes Trânsito
- Cochos para água
- Cavaletes de ferro p/ cochos
- Cones GRANDES
- Cones PEQUENOS
- Tina 1000L
- Palet Ferro
- Palet Plástico
- Rampas de madeira
- Prismas (cavaletes grandes)

Esses itens devem vir automaticamente na requisição quando o usuário selecionar o template “Percurso”, mas o usuário precisa poder:
- editar as quantidades;
- excluir itens que não serão usados;
- adicionar novos produtos;
- preencher observação por item;
- preencher uma observação geral da requisição.

--------------------------------------------------
1. OBJETIVO DO MÓDULO
--------------------------------------------------

Criar um módulo completo de “Templates de Requisição” com frontend e backend.

Esse módulo deve permitir:

1. Cadastro de templates por área/departamento.
2. Cadastro de itens padrão dentro de cada template.
3. Quantidade padrão opcional por item.
4. Observação padrão opcional por item.
5. Ativar/inativar templates.
6. Editar templates existentes.
7. Duplicar template.
8. Excluir template, com confirmação.
9. Usar template na criação de uma requisição.
10. Permitir que o usuário ajuste os itens antes de enviar a requisição.

--------------------------------------------------

Substituir o modal atual por um drawer ou modal grande, bem organizado e sem parecer improvisado.

Título:

Campos principais:

  Exemplo: Percurso

4. EDIÇÃO RÁPIDA DE QUANTIDADES
--------------------------------------------------

Na tela de edição do template, as quantidades precisam ser fáceis de ajustar.

A quantidade padrão deve ser editável diretamente na tabela de itens.

Exemplo:

Produto                         SKU                  Qtd padrão     Unidade      Obs
Cavaletes Trânsito              CAV_TRANS            [ 20 ]         unit         -
Cones GRANDES                   CONE_G               [ 50 ]         unit         -
Tina 1000L                      TINA_1000L           [ 2 ]          unit         -

A experiência deve ser parecida com uma planilha simples:
- fácil de alterar quantidade;
- fácil de apagar item;
- fácil de adicionar novo produto;
- salvar tudo de uma vez.

--------------------------------------------------
6. USO DO TEMPLATE NA CRIAÇÃO DE REQUISIÇÃO
--------------------------------------------------

A tela de criação de requisição precisa permitir selecionar um template.

Fluxo esperado:

1. Usuário cria nova requisição.
2. Seleciona o evento.
3. Seleciona a área/departamento.
4. Sistema sugere templates ativos daquela área.
5. Usuário escolhe um template.
6. Sistema pré-preenche os itens automaticamente.
7. Usuário edita quantidades.
8. Usuário remove itens que não serão usados.
9. Usuário adiciona itens extras se necessário.
10. Usuário preenche observações.
11. Envia para aprovação.

Importante:
- O template não deve travar a requisição.
- Ele serve como ponto de partida.
- Depois de aplicado, a requisição deve ter sua própria lista de itens.
- Alterar o template depois não deve alterar requisições já criadas.
