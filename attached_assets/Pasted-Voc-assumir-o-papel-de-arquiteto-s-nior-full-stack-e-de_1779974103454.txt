Você assumirá o papel de arquiteto sênior full-stack e deverá revisar este projeto Replit antes de alterar qualquer código.

Contexto:
Este é um sistema web chamado EventFlow Logistics, usado para gestão logística de materiais para eventos. Ele possui back-end em Node.js + Express + TypeScript, banco PostgreSQL com Drizzle ORM, autenticação com Passport/session, front-end em React + TypeScript + Vite, TanStack Query, shadcn/ui e Tailwind.

Objetivo:
Quero melhorar o sistema com segurança, sem quebrar regras de negócio existentes, tanto no front-end quanto no back-end.

Antes de alterar qualquer arquivo, faça uma auditoria completa e me entregue um plano técnico dividido em fases.
