# Prompt para Replit - Relatório de Simulação de Posição de Estoque por Período

## 📋 Contexto do Sistema

Desenvolver um **relatório de simulação de posição de estoque por período** que permita visualizar o saldo projetado de todos os produtos do galpão considerando as alocações temporais das ordens de carregamento e suas respectivas viagens.

## 🎯 Objetivo Principal

Criar uma funcionalidade que simule a posição de estoque ao longo do tempo, considerando quando os materiais estarão indisponíveis (em evento ou em trânsito) baseado nas datas de carregamento e descarregamento das ordens selecionadas.

### **2. Lógica de Cálculo de Períodos**

#### **Regras de Negócio para Períodos:**
```javascript
// Função para calcular período de indisponibilidade
const calcularPeriodoIndisponibilidade = (ordem) => {
  let dataInicioMaisAnterior = null;
  let dataFimMaisTardio = null;
  let temMultiplasViagens = false;
  let detalhePeriodo = "";

  if (ordem.viagens && ordem.viagens.length > 0) {
    // Caso 1: Ordem com viagens atreladas
    ordem.viagens.forEach(viagem => {
      if (!viagem.dataCarregamento || !viagem.dataDescarregamento) {
        throw new Error(`Viagem ${viagem.id} sem datas completas`);
      }

      if (!dataInicioMaisAnterior || viagem.dataCarregamento < dataInicioMaisAnterior) {
        dataInicioMaisAnterior = viagem.dataCarregamento;
      }

      if (!dataFimMaisTardio || viagem.dataDescarregamento > dataFimMaisTardio) {
        dataFimMaisTardio = viagem.dataDescarregamento;
      }
    });

    if (ordem.viagens.length > 1) {
      temMultiplasViagens = true;
      detalhePeriodo = `Múltiplas viagens: ${ordem.viagens.length} viagens entre ${formatDate(dataInicioMaisAnterior)} e ${formatDate(dataFimMaisTardio)}`;
    } else {
      detalhePeriodo = `Viagem única: ${formatDate(dataInicioMaisAnterior)} até ${formatDate(dataFimMaisTardio)}`;
    }

  } else if (ordem.dataCarregamento && ordem.dataDescarregamento) {
    // Caso 2: Ordem com período próprio
    dataInicioMaisAnterior = ordem.dataCarregamento;
    dataFimMaisTardio = ordem.dataDescarregamento;
    detalhePeriodo = `Período da ordem: ${formatDate(dataInicioMaisAnterior)} até ${formatDate(dataFimMaisTardio)}`;

  } else {
    // Caso 3: Ordem sem período definido - ERRO
    throw new Error(`Ordem ${ordem.codigo} sem período definido`);
  }

  return {
    dataInicio: dataInicioMaisAnterior,
    dataFim: dataFimMaisTardio,
    temMultiplasViagens,
    detalhePeriodo,
    diasIndisponivel: calcularDiasEntre(dataInicioMaisAnterior, dataFimMaisTardio)
  };
};
```

const ProdutoRow = ({ produto }) => {

  const getStatusColor = (utilizacao) => {

              {expandido ? '▼' : '▶'}

              <div className="text-sm font-medium text-gray-900">{produto.nome}</div>

            </div>
          </div>
        </td>

          </span>
        </td>

### **5. Validações e Tratamento de Erros**

#### **Validações Pré-Geração:**
```javascript
const validarDadosParaRelatorio = (ordensCarregamento) => {
  const erros = [];
  const avisos = [];

  ordensCarregamento.forEach(ordem => {
    try {
      // Validar se ordem tem período definido
      const periodo = calcularPeriodoIndisponibilidade(ordem);
      
      // Verificar múltiplas viagens
      if (periodo.temMultiplasViagens) {
        avisos.push({
          tipo: 'multiplas_viagens',
          ordem: ordem.codigo,
          detalhes: periodo.detalhePeriodo
        });
      }
      
    } catch (error) {
      erros.push({
        tipo: 'periodo_indefinido',
        ordem: ordem.codigo,
        erro: error.message
      });
    }
  });

  return { erros, avisos };
};

// Componente de Alertas
const AlertasValidacao = ({ erros, avisos }) => {
  if (erros.length === 0 && avisos.length === 0) return null;

  return (
    <div className="mb-6 space-y-3">
      {/* Erros Críticos */}
      {erros.length > 0 && (
        <div className="bg-red-50 border border-red-200 rounded-lg p-4">
          <h3 className="text-red-800 font-medium mb-2">❌ Erros Encontrados:</h3>
          <ul className="text-red-700 text-sm space-y-1">
            {erros.map((erro, index) => (
              <li key={index}>• {erro.ordem}: {erro.erro}</li>
            ))}
          </ul>
          <p className="text-red-600 text-sm mt-2 font-medium">
            Corrija estes erros antes de gerar o relatório.
          </p>
        </div>
      )}

      {/* Avisos */}
      {avisos.length > 0 && (
        <div className="bg-yellow-50 border border-yellow-200 rounded-lg p-4">
          <h3 className="text-yellow-800 font-medium mb-2">⚠️ Avisos:</h3>
          <ul className="text-yellow-700 text-sm space-y-1">
            {avisos.map((aviso, index) => (
              <li key={index}>• {aviso.ordem}: {aviso.detalhes}</li>
            ))}
          </ul>
        </div>
      )}
    </div>
  );
};
```
